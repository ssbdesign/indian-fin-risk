# Data dictionary and provenance

## Research scope
Equities: SBIN.NS (State Bank of India), HDFCBANK.NS, ICICIBANK.NS and AXISBANK.NS; market benchmark ^NSEI (NIFTY 50). Descriptive figures cover 192 monthly returns per series (2010-2025). Macro-factor models cover **131 monthly observations per bank: February 2015-December 2025**. Missing macro observations before 2015 are not imputed; the two samples should never be conflated.

## Core files and variable definitions

| Path / column | Definition and units |
| --- | --- |
| `data/processed/monthly_returns_all.csv`: `month_end_close` | Final available trading-day close for calendar month (price-level series; confirm historical corporate-action adjustment settings) |
| `monthly_return_pct` | 100 × (current month-end close / previous month-end close − 1); percentage points of monthly return |
| `data/processed/repo_rate_monthly.csv`: `repo_rate_pct` | RBI policy repo rate applicable to the month; percent per annum |
| `repo_rate_change_pp` | Monthly change in repo rate, percentage points (not percent return) |
| `data/processed/india_vix_monthly.csv`: `india_vix_mean` | Arithmetic average of available daily India VIX closing levels in a calendar month; quoted volatility-index points |
| `india_vix_lag1` | Prior month's final India VIX closing level, **not** the lag of monthly average |
| `data/processed/usd_inr_monthly.csv`: `usd_inr_change_pct` | 100 × (USD/INR month-end close / previous month-end close − 1); INR per USD. Positive means INR depreciation |
| `usd_inr_change_pct_lag1` | Prior month's USD/INR percent change |
| `nifty_return_pct` | Same-month NIFTY 50 index return used as broad-market control |

## Data lineage
- Repo rate: preprocessed from historical RBI rate workbooks under `data/raw/rbi_repo_rate/`, ultimately sourced from RBI series. Confirm end-of-month timing with the original policy effective-date series.
- Equity/index historical daily data: the project's validated price CSVs; their earlier ingestion scripts and provider settings should be reviewed for adjustment, dividends, splits and survivorship before publication.
- India VIX: daily Yahoo Finance `^INDIAVIX` series generated by `src/download_macro_factors.py`, then aggregated monthly.
- USD/INR: daily Yahoo Finance `INR=X`, then month-end percent change. Compare against RBI reference rates for source consistency.
- Official documentation: https://www.rbi.org.in/Scripts/bs_viewcontent.aspx?Id=624 ; https://www.nseindia.com/static/products-services/indices-indiavix-index ; https://www.nseindia.com/static/products-services/indices-nifty50-index .

## Modeling
Baseline: repo-rate level, repo-rate monthly change, contemporaneous NIFTY return. Expanded same-month: baseline plus India VIX monthly average and USD/INR monthly percent change. Expanded lagged: baseline plus prior-month India VIX **close** and prior-month USD/INR percent change. Each bank/specification uses the same complete-case 131 months. OLS standard errors use HAC/Newey-West with `maxlags=3`. Neither same-month models nor the "lagged" specification with a same-month NIFTY control should be called a real-time forecasting system. Estimated relationships are associative, not causal.

## Reproducibility and caution
```bash
python src/build_analysis_dataset.py
python src/run_expanded_macro_analysis.py
python src/generate_research_outputs.py
python src/run_robustness_checks.py
```
Do not rerun the Yahoo download unless the monthly factor files are missing and a new data snapshot is intended. Robustness excludes March-December 2020 inclusive, retaining 121 observations per bank. The committed `reports/results/robustness_key_results.csv` is a **rounded transcription of an observed successful local run**, not a substitute for the full-precision output that `run_robustness_checks.py` creates locally.

Interpret p-values cautiously due to multiple comparisons, possible policy endogeneity, data-vendor differences, market factor co-movement and exceptional periods. The original study did not include CPI/inflation, out-of-sample forecasting, announcement-timestamp surprises or an independent stock-return adjustment audit. The V2 historical forecasting evaluation is documented below; the other omissions remain.

## V2 extension on 12 November 2026

Inputs remain frozen. `download_market_data.py` requests `auto_adjust=True`; this establishes the intended provider setting but is not an independent price or corporate-action reconciliation.

- **VIX alternative:** `india_vix_change` is the difference in successive month-end VIX closes, in index points.
- **Calendar HAC:** Bartlett weights and maxlags=3 match the original convention on contiguous samples. Omitted months receive zero score contributions, preserving calendar distances across gaps.
- **Test families:** 16 same-month macro coefficients (4 banks x 4 factors excluding NIFTY); broader 40-test macro family; four joint VIX/FX tests; four exploratory break tests. BH and Holm outputs retain all coefficients, not just nominally significant ones.
- **Forecasts:** fully prior-month bank return, NIFTY return, repo level/change, VIX mean and FX change; 60 initial training observations; expanding refits; 70 forecasts per bank from 2020-03 to 2025-12. These retrospective results do not use current-month factors and do not imply a live untouched evaluation.
- **Corrected events:** inclusive daily return windows [-1,+1] and [-5,+5] require starting closes at t-2 and t-6. The original outputs use t-1 and t-5 starting closes and thus two and ten intervals. V2 saves actual endpoint dates, corrected test families of 15 raw and 12 relative tests, a combined 27-test family and a 45-test family including the legacy alternative windows without duplicating event day.
- **Interpretation:** bank-minus-index is a raw difference, not beta-adjusted abnormal return. Effective dates do not identify announcement surprises. No overlapping corrected event windows were found, which does not prove independent events.

Run `python src/run_research_v2.py`, then `python src/plot_research_v2.py`. Outputs, input SHA-256 hashes and versions are under `reports/v2/`. The original data and legacy numerical tables remain available.
